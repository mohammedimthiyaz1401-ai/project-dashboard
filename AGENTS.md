## LinkedIn Content Section
- 8 trending topics: AI Agents, Healthcare AI, Edge AI, AI Security, Vibe Coding, RAG, Business AI, Open Source Models
- Each has: trend description, post idea, hashtags, "Post on LinkedIn" link
- Weekly posting schedule: Mon-Sun topic rotation
- Best times: 8-10 AM or 5-7 PM IST

## Dashboard Rules
- Add new repos to: Quick Links, GitHub Repos, PROJECT URLS
- Add new emails to Email Accounts section
- Add new YouTube channels to YT_REPOS in checkYouTubeStatus()
- Update badge when project status changes
- Always commit + push after edits

## MEOW Commands
- `scroll to [section]` — scrolls to any section
- `hide/show [section]` — toggles section visibility
- Copy buttons on all email addresses
- Clickable stat tiles scroll to respective sections
